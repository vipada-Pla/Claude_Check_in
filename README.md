# ระบบเช็คชื่อ Claude AI Class

เว็บเช็คชื่อผู้เข้าเรียน ใช้ได้ทั้งคอม แท็บเล็ต และมือถือ
ผู้เรียนกด **เช็คชื่อ** → เซ็นชื่อ → **Approve** ระบบจะบันทึก **เวลา + สถานะ (ตรงเวลา/สาย) + ลายเซ็น** ลง **Google Sheets** ทันที

```
หน้าเว็บ (GitHub Pages)  ──►  Google Apps Script (Web App)  ──►  Google Sheet + Google Drive (ลายเซ็น)
```

## ไฟล์ในโปรเจกต์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บเช็คชื่อ (ไฟล์เดียว รวม CSS/JS แล้ว) |
| `config.js` | ใส่ลิงก์ Web App ของ Google Apps Script |
| `apps-script/Code.gs` | โค้ดหลังบ้าน สำหรับวางใน Google Apps Script |
| `apps-script/appsscript.json` | ค่าตั้งของ Apps Script (เขตเวลา Asia/Bangkok) |
| `sample/roster-template.csv` | ตัวอย่างไฟล์รายชื่อสำหรับนำเข้า |

> ⚠️ **ห้ามใส่ไฟล์รายชื่อจริง (ชื่อ เบอร์โทร อีเมล) ลงใน GitHub** เพราะ repo สาธารณะใครก็เปิดดูได้
> ให้นำเข้ารายชื่อผ่านหน้าเว็บ หรือวางลงใน Google Sheet โดยตรงแทน

## ขั้นตอนติดตั้ง (ครั้งแรก ประมาณ 10–15 นาที)

### ขั้นที่ 1 — สร้าง Google Sheet + วางโค้ดหลังบ้าน

1. เปิด https://sheets.new สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น `เช็คชื่อ Claude AI Class`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมใน `Code.gs` ทิ้ง แล้ววางเนื้อหาจากไฟล์ `apps-script/Code.gs` ลงไป
4. **เปลี่ยนรหัสผู้ดูแล** ที่บรรทัด `const ADMIN_KEY = 'CHANGE-ME-1234';` เป็นรหัสของคุณเอง
   (ใส่รหัสจริงเฉพาะใน Apps Script เท่านั้น **ไม่ต้องแก้ในไฟล์บน GitHub**)
5. กด 💾 บันทึก
6. (แนะนำ) ⚙️ **Project Settings** → ติ๊ก *Show "appsscript.json"* → เปิดไฟล์ `appsscript.json` แล้ววางเนื้อหาจาก `apps-script/appsscript.json`

### ขั้นที่ 2 — รัน setup ครั้งแรก

1. ด้านบนเลือกฟังก์ชัน **`setup`** → กด **▶ Run**
2. Google จะขอสิทธิ์ → **Review permissions** → เลือกบัญชี → *Advanced* → *Go to … (unsafe)* → **Allow**
   (ขึ้นคำว่า unsafe เพราะเป็นสคริปต์ที่เราเขียนเอง ไม่ได้ผ่านการรับรองจาก Google — ปลอดภัย)
3. กลับไปดู Google Sheet จะมีชีต **Roster**, **Checkins**, **Config** พร้อมหัวตาราง
   และใน Google Drive จะมีโฟลเดอร์ **Claude AI Class - Signatures** (เก็บรูปลายเซ็น)

### ขั้นที่ 3 — Deploy เป็น Web App

1. ปุ่ม **Deploy → New deployment**
2. ⚙️ Select type → **Web app**
3. ตั้งค่า
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
4. กด **Deploy** → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### ขั้นที่ 4 — ใส่ลิงก์ในหน้าเว็บ

เปิดไฟล์ `config.js` แล้ววางลิงก์

```js
window.ATTENDANCE_CONFIG = {
  APPS_SCRIPT_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
  REFRESH_SECONDS: 15
};
```

> ลิงก์นี้ไม่ใช่ความลับระดับรหัสผ่าน (คนที่มีลิงก์ทำได้แค่ดูรายชื่อและเช็คชื่อ)
> งานผู้ดูแลทุกอย่างต้องใช้ `ADMIN_KEY`

### ขั้นที่ 5 — ขึ้น GitHub Pages

1. สร้าง repository ใหม่ใน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → **Save**
3. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`

### ขั้นที่ 6 — นำเข้ารายชื่อ

1. เปิดหน้าเว็บ → เลื่อนลงล่างสุด กด **🔒 ผู้ดูแล** → ใส่ `ADMIN_KEY`
2. กด **นำเข้า CSV / Excel** → เลือกไฟล์
   - รองรับไฟล์ตอบกลับจาก **Google Form** ที่ลงทะเบียนได้หลายคน (คอลัมน์ `ชื่อ-นามสกุล 2`, `3`, …) — ระบบแยกเป็นรายคนให้อัตโนมัติ
   - ตัดคำนำหน้า (นาย/นาง/นางสาว) และข้ามชื่อซ้ำให้อัตโนมัติ
3. หรือจะพิมพ์/วางรายชื่อในชีต **Roster** ใน Google Sheet โดยตรงก็ได้ (คอลัมน์ ID เว้นว่างไม่ได้ ให้ใส่รหัสอะไรก็ได้ที่ไม่ซ้ำ เช่น p001, p002)

## การใช้งานวันเรียน

| ใคร | ทำอะไร |
|---|---|
| ผู้เรียน | เปิดลิงก์ (หรือสแกน QR) → หาชื่อตัวเอง → **เช็คชื่อ** → เซ็น → **Approve** |
| ผู้ดูแล | เข้าโหมดผู้ดูแล → ดูสรุป มาแล้ว / ตรงเวลา / สาย / ยังไม่มา แบบเรียลไทม์ (อัปเดตทุก 15 วินาที) |
| ผู้ดูแล | ⚙️ ตั้งค่า → ชื่อคลาส, เวลาเริ่มเรียน, เวลาผ่อนผัน (นาที) |
| ผู้ดูแล | ⋮ ข้างชื่อ → แก้ไข / ยกเลิกการเช็คชื่อ / ลบรายชื่อ |
| ผู้ดูแล | **เปิด Google Sheet** → ดูข้อมูลดิบ, ลิงก์รูปลายเซ็น, ทำรายงานต่อ |

**ข้อมูลใน Google Sheet (ชีต Checkins)**
วันที่เรียน · ID · ลำดับ · ชื่อ-นามสกุล · บริษัท · ตำแหน่ง · เวลาเช็คชื่อ · สถานะ · สาย (นาที) · ลิงก์ลายเซ็น

- เวลาที่บันทึกเป็น **เวลาของเซิร์ฟเวอร์ Google** (โซนเวลาไทย) ผู้เรียนแก้นาฬิกาในมือถือก็โกงเวลาไม่ได้
- เช็คชื่อซ้ำไม่ได้ — ถ้ากดซ้ำ ระบบจะแจ้งเวลาที่เช็คไปแล้ว
- เรียนหลายวัน: เลือก **วันที่เรียน** ที่หัวเว็บ ข้อมูลแต่ละวันแยกกัน

## เมื่อแก้โค้ด Apps Script ภายหลัง

ต้อง **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy**
(ลิงก์ `/exec` เดิมใช้ต่อได้ ไม่ต้องแก้ `config.js`)

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| หัวเว็บขึ้น "โหมดเครื่องนี้ (ยังไม่ได้เชื่อม Google Sheets)" | ยังไม่ได้ใส่ลิงก์ใน `config.js` |
| ขึ้น "เชื่อมต่อ Google Sheets ไม่ได้" | ตรวจว่า Deploy แบบ *Who has access: Anyone* และลิงก์ลงท้าย `/exec` |
| ใส่รหัสผู้ดูแลแล้วขึ้น "รหัสไม่ถูกต้อง" | แก้ `ADMIN_KEY` แล้วยังไม่ได้ Deploy เวอร์ชันใหม่ |
| แก้ไฟล์บน GitHub แล้วหน้าเว็บไม่เปลี่ยน | รอ 1–2 นาที แล้วกดรีเฟรชแบบล้างแคช (Ctrl+Shift+R) |

## ข้อจำกัด

- Google Apps Script รองรับการใช้งานพร้อมกันได้ราว 30 คำขอ/ครั้ง เพียงพอสำหรับคลาสหลักสิบถึงร้อยคน
- การเช็คชื่อแต่ละครั้งใช้เวลาประมาณ 1–3 วินาที (ขึ้นกับความเร็ว Google)
- ถ้าเปิด `index.html` โดยไม่มี `config.js` หรือไม่ใส่ลิงก์ ระบบจะเก็บข้อมูลในเบราว์เซอร์ของเครื่องนั้นเท่านั้น
